Entry for the make.fun bounty [The One-Liner Groan-Off](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5).

`main.py` (Python 3.13, standard library only) writes one original
one-line dad joke to `/output/entry.txt`:

> I asked the dryer where my third left sock went this week, and it said the case is still spinning.

Run it with:

```sh
python3 -P -s main.py
```
